# 更新操作单 — 2026-08-02（媒体字段 + 低频取数修复）

本次变更：`content_item` 新增 `image_url` 列；RSS 抓取提取图/音/视频；富化任务回填 og:image；
`DataSourceOut` 新增 `icon_url`/`avatar_url`；company 派生 `logo_url`;
`GET /api/v1/content/{module}` 不传 `date` 且当天为空时回退返回最新 N 条。

## 1. 数据库

生产库（RDS polaris）**已执行**，无需操作：

```sql
ALTER TABLE content_item ADD COLUMN IF NOT EXISTS image_url TEXT;  -- 已执行 2026-08-02
```

新环境建表用最新 `deploy/schema.sql` 即含该列。

## 2. 服务器更新

```bash
cd /opt/datahub/app && git pull
cd deploy && docker compose build api scheduler && docker compose up -d api scheduler
```

## 3. 验证

```bash
# 新闻带图（新入库条目;富化最迟 15 分钟补齐 og:image）
curl -s "https://mai.polarisagi.com/api/v1/content/news?by=fetched&limit=5" | grep -o '"image_url":"[^"]*"' | head -3
# 播客带音频
curl -s "https://mai.polarisagi.com/api/v1/content/channel?by=fetched&limit=20" | grep -o '"audio_url":"[^"]*"' | head -1
# 数据源 favicon
curl -s "https://mai.polarisagi.com/api/v1/sources?limit=1" | grep -o '"icon_url":"[^"]*"'
# 低频模块不再返空
curl -s "https://mai.polarisagi.com/api/v1/content/calendar?limit=3" | head -c 200
```

## 4. 可选配置（默认即可）

| 变量 | 默认 | 说明 |
|---|---|---|
| `DATAHUB_FAVICON_SERVICE_URL` | Google s2 favicon 模板 | 消费端在境内访问受限时换成国内可达服务，`{domain}` 占位 |
| `DATAHUB_STOCK_LOGO_SERVICE_URL` | FMP 公开图片 CDN 模板 | company logo 取图地址，`{symbol}` 占位；置空禁用 |
