## 验收清单

```bash
# 1. 版本与容器状态
docker compose ps                         # api / scheduler 均 running

# 2. 调度任务齐全(应含 enrich、purge、refresh-all)
docker compose logs scheduler | grep "job kinds"
#    期望: {'interval': ..., 'cron': ..., 'refresh': 1, 'enrich': 1, 'purge': 1}

# 3. API 正常且新字段在
curl -s "http://127.0.0.1:8000/api/v1/content/news?limit=1&by=fetched" | grep -c fulltext
#    期望: 1

# 4. GN 解码生效(部署后等一个富化周期 ~15 分钟再查)
docker compose logs scheduler | grep "fulltext enrich"
#    期望: 日志含 canonical_resolved > 0,如
#    fulltext enrich: {'attempted': 200, 'extracted': ~90+, 'canonical_resolved': ...}
```

## 可选调优

存量 GN 重处理约 1.8 万条,默认节奏(200 条/15 分钟)约需 1 天。如需加速,
在 `/opt/datahub/app/.env` 追加后重启 scheduler:

```bash
DATAHUB_FULLTEXT_BATCH_SIZE=500
DATAHUB_FULLTEXT_INTERVAL_MINUTES=5
```

注意:富化过程会请求 Google 的解码接口,批次过大可能触发对方限流
(表现为日志中 `deferred` 计数升高,属自动重试范围,无需处理)。
