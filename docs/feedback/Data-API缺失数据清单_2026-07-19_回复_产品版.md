# 数据服务更新说明（回复 7-19 缺失数据清单）— 产品版

**日期** 2026-08-02（当日两批更新）· **给** 产品团队
清单所提问题已逐项核实：能做的已经上线，其余如实说明条件与时点。
**第二批追加**：拿到 FMP 等数据服务的 key 后，原"待数据源接入"的结构化行情/财务/日历数据
当天已大部分上线，接口说明与可直接执行的测试用例见 §三。

## 一、本次已上线

1. **内容配图** —— 新闻、事件等内容现在带配图。来源自带的抓取即有；来源没给的，系统会在入库后约 15 分钟内从原文页自动补一张。Stories 卡缩略图、事件头图、相关推荐缩略图、Library 卡都可以直接用，不用再回查其他接口。
2. **来源图标** —— 每个数据源都带统一尺寸（64px）的站点图标。清单里提到的"头像位无字段可用"已解决：头像字段即刻可用，当前取值为站点图标，后续接入各平台真实头像时**前端不需要任何改动**。
3. **播客音频** —— 播客节目带可直接播放的音频地址、格式和时长。Podcast 详情页播放态、Floating Station 的 now playing 都可以接了。
4. **视频** —— 视频类内容带播放地址（YouTube 内容另带视频 ID）。如实说明：目前登记的视频来源以频道主页为主，能直接出视频的来源还不多，覆盖会随来源清单完善而提升。
5. **低频栏目"取不到数据"** —— 清单第三节提到的老问题，确认属实，已修复。日历、宏观、市场这类几天才更新一次的栏目，以前当天没有新内容就返回空，现在会自动返回最近的内容；三个栏目已验证都能正常取数。

## 二、能力已就绪、待条件到位（前端无需二次改造）

1. **公司 logo** —— 取图能力已上线且无需付费：公司内容只要带股票代码就自动带 logo。股票代码的填充和"结构化财务数据"是同一批（Wave3），数据源接入即全量生效。
2. **结构化行情/财务/估值/日历/宏观数值** —— ~~待数据源接入~~ **已上线**（FMP + FRED 数据服务已接入，详见 §三）；仅"个股财务明细"还需先确定监控股票清单。
3. **关键人物内容** —— 待 twitterapi.io 付费开通（商务决策），开通后 256 个人物源自动流入。本次收到的 twitter key 经验证**不是 twitterapi.io 的 key**（无法使用），仍需在 twitterapi.io 控制台生成。
4. **财报电话会音频** —— 目前来源清单中没有这类源；在来源清单里补登后即自动抓取，播客侧音频已验证跑通。

## 三、第二批更新：结构化数据已上线（接口说明 + 测试用例）

接入 FMP 数据服务后，以下结构化数据已入库并持续更新（每 4 小时刷新，行情为每日快照）。
不需要新接口——都从现有的内容接口取，数值在 `payload` 字段里。以下用例可直接在终端执行。

### 3.1 市场行情（market）—— 全球 9 家交易所 + 指数/外汇/加密/商品

每条带 `symbol / price / change / volume`（按成交量取每所最活跃的 100 只）：

```bash
curl "https://mai.polarisagi.com/api/v1/content/market?by=fetched&limit=2"
```
```json
[{"title": "GBPHKD 10.57 (+0.0098)", "published_at": "2026-08-02T07:50:18",
  "payload": {"symbol": "GBPHKD", "price": 10.57, "change": 0.0098, "volume": 103878}}]
```

想只看某一块，用来源过滤（来源 id 见 `/api/v1/sources?module=market`）：
纽交所 501、纳斯达克 502、伦交所 493、港交所 500、东京 JPX 498、韩国 KRX 503、多伦多 TSX 496、
泛欧 499、印度 497、指数/ETF 495、外汇 524、加密 531、商品 514。

```bash
curl "https://mai.polarisagi.com/api/v1/content?source_id=501&limit=5"   # 纽交所当日最活跃
```

### 3.2 财报日历（calendar）—— 含 EPS 实际值/预期值

```bash
curl "https://mai.polarisagi.com/api/v1/content?source_id=408&limit=2"
```
```json
[{"title": "ENB-PFK.TO 财报 2026-07-31",
  "payload": {"symbol": "ENB-PFK.TO", "event_date": "2026-07-31",
              "epsActual": 0.63, "epsEstimated": 0.582}}]
```

分红/拆股日历 `source_id=412`，IPO 日历 `source_id=414`，用法相同。

### 3.3 经济数据日历（calendar）—— 各国指标发布，含实际/预期/前值

```json

  "payload": {"country": "BE", "event": "Harmonised Inflation Rate YoY (Jul)",

```
