## 11 · news 脏时间戳,主犯是源 82

`published_at > fetched_at + 1h` 实测 **547** 条,源 82 占 **545**,其余 307 / 371 各 1;回复里点名源 101 是举错了例子,这点认。

**已改**:近端(阈值以内)按源端时钟/时区错误处理,钳到抓取时刻;远端仍置空。1.5 小时的偏差不值得把日期整个丢掉。
