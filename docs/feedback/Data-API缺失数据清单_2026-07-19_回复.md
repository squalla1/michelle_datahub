## 二、结构化覆盖缺口（B 类，记录）

均非接口缺陷，属数据源接入/商务事项，维持 07-06 回复的分工与排期：

- **行情/财务/估值数值**：非 bug。payload 契约已预留（`symbol/exchange`，本次又加 `logo_url`），数值待结构化源接入（Wave3）；免费官方 API 与 FMP 的优先级仍待业务确认。
- **结构化日历**（`event_datetime/symbol/live_state`）：同上，现状"文档形态"是 SEC 等源本身的形态；结构化字段待结构化日历源接入。**其取数不畅的部分本次已修**（见下"工程动作 4"）。
- **宏观数值化**（`indicator/value/period`）：待 S-MACRO 结构化源（FRED 等，密钥配置项已预留，设上即用）。
- **关键人物**：非 API 缺陷。待 twitterapi.io 商务开通，开通后 person 类 256 个源自动流入，无需改造。
- **结构化事件占比**：GDELT 已接入；ACLED 密钥配置项已预留，UCDP 未接。样本 HN 偏重属注册表源结构，不是路由问题。
- **转写音频源**：播客侧已由 A-4 的 `audio_url` 覆盖并验证；earnings 音频注册表中**无源**——在 Excel 注册表补登对应源后即自动调度抓取。

## 三、给工程的最小动作（清单第三节）

1. `ContentItemOut` 增 `image_url`；payload 增 `audio_url`/`video_url` —— **已完成**（见 A-1/4/5）。
2. `DataSourceOut` 增 `icon_url`/`avatar_url`；company 增 `logo_url` —— **已完成**（见 A-2/3）。
3. 优先级"①新闻图+③favicon 先上" —— **已按此执行**，且 ②④⑤ 同批完成契约。
4. **低频 typed 接口返空 bug —— 确认属实，已修复。** 根因：排重机制不更新入库时间，calendar/macro/market 等低频模块可能连续数日无新条目，默认"当天"窗口下 `by=published`、`by=fetched` 都返空。修复：不传 `date` 且当天为空时，自动回退返回**全库最新 N 条**；显式传 `date` 不回退。生产实测三个模块现均能取到数据（此前全部返 `[]`）。
