**方法**:所有结论按 `fetched_at` **批次分层**裁定 —— 回填改的是历史行、取数改造改的是新行,混在一起看会得出相反结论。
**前置**(以下复现命令共用):

```bash
BASE=https://mai.polarisagi.com/api/v1
dump(){ m=$1; o=0; : > /tmp/$m.json; while :; do r=$(curl -s "$BASE/content?module=$m&limit=500&offset=$o"); n=$(echo "$r" | jq 'length'); echo "$r" | jq -c '.[]' >> /tmp/$m.json; [ "$n" -lt 500 ] && break; o=$((o+500)); done; done
for m in company calendar market macro news opinion; do dump $m; done
```

`limit` 上限 500(501 起 422),分页用 `offset`,`page` 无效。

## 7. 央行五源把官网导航元素当日历事件入库

```bash

```
