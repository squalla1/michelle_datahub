## 逐条验证方法与实测

### A1 内容配图

```bash
curl -s "https://mai.polarisagi.com/api/v1/content/news?by=fetched&limit=50" \
  | python3 -c "import json,sys;d=json.load(sys.stdin);print(sum(1 for x in d if x['image_url']),'/',len(d))"
```
实测 `26 / 50`（单页样本比例受来源轮转影响；全库口径见总览表）。事件同理，把 `news` 换成 `events`。

### A2 公司 logo

```bash
curl -s "https://mai.polarisagi.com/api/v1/content?module=company&limit=20" \
  | python3 -c "import json,sys;d=json.load(sys.stdin);print([x['payload'].get('symbol') for x in d])"
```
实测全为 `None` → 没有股票代码就不会有 logo。契约本身可验证：任一带 `symbol` 的 company 条目在读取时自动生成 `logo_url`（回归测试 `tests/test_media.py`）。
**卡点**：FMP 公司源（`source_id=461`）的"账号"列为空，无监控股票清单时该源整体跳过。填入逗号分隔的股票代码即生效。

### A3 数据源图标 / 头像

```bash
curl -s "https://mai.polarisagi.com/api/v1/sources?limit=1" | python3 -m json.tool | grep -E "icon_url|avatar_url"
```
实测两个字段均有值（Google favicon 服务，64px）。头像位当前取站点图标，后续换真实头像前端无需改动。

### A4 播客音频

```bash
curl -s "https://mai.polarisagi.com/api/v1/content/channel?by=fetched&limit=50" \
  | python3 -c "import json,sys;d=json.load(sys.stdin);a=[x for x in d if x['payload'].get('audio_url')];print(len(a));print(a[0]['payload'] if a else None)"
```
实测返回可直接播放的 `.m4a/.mp3` 地址，并带 `audio_mime`、`audio_duration`。

### A5 视频

```bash
curl -s "https://mai.polarisagi.com/api/v1/content?source_id=57&limit=20" \
  | python3 -c "import json,sys;d=json.load(sys.stdin);print(sum(1 for x in d if x['payload'].get('video_url')),'/',len(d))"
```
实测 `17 / 20`（Africanews，`video_url` 为可直接播放的 mp4）。视频目前均来自新闻源附件（Africanews、El País、RBC、NBC 等），跨模块混排的最新内容里比例很低；`video_id` 全库 0 条。
**原因**：登记表中标注"YouTube RSS"的频道源，URL 填的是 `https://www.youtube.com/@handle`（频道主页），不是可订阅的频道 RSS，实际抓取回落到同一行的播客 RSS。补登频道 RSS 地址即可出视频与 `video_id`。

### B1 行情 / 财报数值

```bash
curl -s "https://mai.polarisagi.com/api/v1/content?source_id=501&limit=3"   # 纽交所行情
curl -s "https://mai.polarisagi.com/api/v1/content?source_id=408&limit=3"   # 财报日历（含 EPS）
```
实测行情条目带 `symbol/price/change/volume`；财报条目带 `epsActual/epsEstimated`。覆盖 19 个行情来源（9 家交易所 + 指数/外汇/加密/商品），最近一次刷新 08-05 04:07 UTC。

### B2 结构化日历

```bash
curl -s "https://mai.polarisagi.com/api/v1/content?source_id=408&limit=1" | python3 -m json.tool   # 财报
curl -s "https://mai.polarisagi.com/api/v1/content?source_id=429&limit=1" | python3 -m json.tool   # 经济
```
实测近 7 天日历栏目 4,365 条中：财报/分红/拆股/IPO 2,547 条带 `event_date + symbol`（注意 `calendar_type` 目前取自登记表的 L2 列，源 408 一律为"美股"，与实际 ticker 不符，待修）；经济日历 231 条带 `date + event + country + impact`，其中 220 条带 `actual/estimate`；其余 1,587 条为原有的文档形态（SEC filings 等网页来源，无结构化字段）。
**未交付**：`live_state`（是否直播中）——数据源不含该状态，建议由引擎按开始时间＋时长推导。

curl -s "https://mai.polarisagi.com/api/v1/content?source_id=543&limit=3"   # FRED 指标
curl -s "https://mai.polarisagi.com/api/v1/content?source_id=510&limit=3"   # 美债收益率（市场栏目）

实测 `{"indicator":"T10Y2Y","value":0.43,"period":"2026-08-04"}` 等；来源 543/547/510 最近运行状态均为 `ok`（`/api/v1/sources/543/runs`）。
> 更正 8-02 回复：当时因本机网络无法连通 FRED 而标注"待验证"，服务器侧已确认正常出数。

```bash
curl -s "https://mai.polarisagi.com/api/v1/content?module=person&limit=5"
```
实测 `[]`。twitterapi.io 未开通；8-02 提供的 twitter key 经验证不是该服务的 key。开通后 256 个人物源自动流入，无需改代码。

### B5 事件源构成

```bash
curl -s "https://mai.polarisagi.com/api/v1/sources?module=events" | python3 -m json.tool | grep -E '"name"|"method"'
curl -s "https://mai.polarisagi.com/api/v1/content/events?by=fetched&limit=50" | python3 -m json.tool | grep '"source_id"' | sort | uniq -c
```
实测近 7 天：GDELT 系 7 个来源共 815 条，其他（GitHub Trending + Show HN 等）749 条 —— 7-19 清单所说"样本 HN-heavy"已明显改善。ACLED 的 3 个来源（`id` 390/396/400）仍因未开通 key 无产出。

### B6 音频/转写源

播客音频见 A4。财报电话会音频：登记表中该类来源目前只有文字稿网页（如 Motley Fool Transcripts），没有音频源；补登任一带 enclosure 的音频 feed 即自动抓取，管线已验证。

### E4 低频栏目返空的老 bug

```bash
for m in calendar macro market; do
  echo -n "$m: "; curl -s "https://mai.polarisagi.com/api/v1/content/$m?by=fetched&limit=3" \
    | python3 -c "import json,sys;d=json.load(sys.stdin);print(len(d), d[0]['title'] if d else '')"
done
```
实测三个栏目分别返回 3 条（`[US] OPEC Meeting` / `T10Y2Y = 0.43` / `IMXUSD 0.1107`），不再返空。规则：不带 `date` 参数时当天无内容会自动回退到最近内容；显式指定 `date=` 则严格按日期，不回退。
